# A Boat · 功能介绍与扩展选型指南

> **A Boat · 一苇杭之。** 一个塞进单个 HTML 文件的离线 Markdown 编辑器：不装软件、不连网络、不上传一个字。名字取自《诗经》「谁谓河广，一苇杭之」—— 一片苇叶就能渡河，一个文件就能写完。

本文件既是使用说明，也按不同使用场景给出扩展搭配建议。你可以用 A Boat 直接打开它（双击同目录的 `index.html`），边读边看。

---

## 一、它能做什么

整个编辑器只有一层解析器加三层界面，所有内容只存在你的浏览器里。

### 1. 边写边看

- **三种视图**：仅编辑 / 分屏 / 仅预览，中间分隔条可拖动调宽。
- **双向滚动同步**：两边按比例对齐，滚哪边都不会错位。
- **文档大纲**：自动收集 `#`~`######`，跳过代码块里的假标题，点击即可跳转。
- **智能续写**：列表里按 `Enter` 自动续写下一项（有序列表自动加一、任务列表补空框）；空项再按一次 `Enter` 退出列表。引用行同理。
- **整段缩进**：`Tab` / `Shift+Tab` 对选中多行整体缩进或反缩进。

### 2. 公式不用联网

KaTeX 引擎连同 20 个字体文件全部内嵌，断网也能渲染。支持四种写法：

| 写法 | 示例           | 用途       |
| :- | :----------- | :------- |
| 行内 | `$E = mc^2$` | 行内公式     |
| 块级 | `$$ … $$`    | 居中独立公式   |
| 行内 | `\( … \)`    | LaTeX 行内 |
| 块级 | `\[ … \]`    | LaTeX 块级 |

`$5` 这类价格不会误判成公式，代码块里的美元符号也不会被打扰；语法出错时在原位置显示红色提示框，不会整篇崩掉。

### 3. 不会丢字

停止输入约半秒后自动写入本机存储（标题 + 正文一起存），下次打开原样恢复。顶栏小圆点实时显示保存状态，绿了就是存好了。

### 4. 随时带走

- **`Ctrl + S`** 存成 `.md` 文件（优先用系统「另存为」对话框，不支持则自动下载）。
- **「导出 HTML」** 生成独立单文件，正文排版、KaTeX 字体、代码配色、扩展注入的样式一起打包，发到哪都能看。
- **拖拽打开**：把 `.md` 文件直接拖进窗口即可载入。
- **打印友好**：打印样式只输出正文，顶栏和编辑区自动隐藏。

### 5. 七套主题

晴川、琥珀、青松、碧海、绯樱、夜航、石墨。每套都有独立的强调色、选区、高亮与代码底纹，选择后记在本机；暗色主题下代码高亮和公式也跟着换色，不是简单反相。

## 二、键盘快捷键

Windows 用 `Ctrl`，macOS 用 `⌘`，两套都认。

| 操作   |         快捷键        | 操作     |         快捷键        |
| :--- | :----------------: | :----- | :----------------: |

| 删除线  | `Ctrl + Shift + X` | 高亮     | `Ctrl + Shift + H` |

## 三、扩展系统简介

A Boat 最特别的地方是**能长出新语法**。一个扩展就是一个 `.mext` 文件（普通 JavaScript），导入后在页面内执行：

```js
// 一个扩展就是一个 .mext 文件
api.register({
  name: '容器块语法',   // 名称
  icon: '📦',           // 列表里显示的图标
  init: function (ctx) {
    // ctx.md   自定义语法：addBlockRule / postTransform / inline …
    // ctx.ui   界面：addButton / addCommand
    // ctx.app  编辑器：getValue / setValue / insertText / panel …
  },
  dispose: function () { /* 停用时清理注入的样式与监听 */ }
});
```

导入方式：顶栏「扩展」按钮 → 导入扩展 → 选文件。面板里可启用 / 停用 / 删除，同名扩展再次导入会替换旧的；扩展被停用时会自动调用 `dispose` 清理资源。

> ⚠️ 扩展会作为 JavaScript 在本页执行，请只导入你信任的来源。

## 四、按需选用扩展（针对不同用户）

下面按使用角色给出搭配建议。**未特别说明的，编辑器本体已自带**，无需装扩展。

### 🎓 学生 / 笔记党

- **推荐：`ext-admonition.mext` + `ext-emoji.mext`**
- 为什么：听课、整理知识点时，`:::tip` / `:::warning` 这样的提示框能把「易错点」「重点」和正文区分开，复习扫一眼就有重点；Emoji 短码让笔记不那么干巴巴。
- 用法要点：容器块语法 `:::tip 标题 … :::`，标题可省略；Emoji 用 `:smile:` 这类短码，代码块里不会被误换。
- 公式（数理化题目）直接用内置 KaTeX，不需要额外扩展。

### 💻 技术写作者 / 程序员 / 文档工程师

- **推荐：`ext-syntax-highlight.mext`（必装）+ `ext-admonition.mext`**
- 为什么：文档里贴代码如果没有高亮，可读性差一大截；语法高亮支持 30+ 语言、明暗自适应，导出 HTML 也保留颜色。提示框用来写「注意」「版本要求」很顺手。
- 用法要点：围栏代码块写语言名即自动着色；与洛谷扩展可共存（后者检测到本扩展存在会让出代码块）。

### 🏆 算法竞赛选手 / 洛谷用户

- **推荐：`ext-luogu.mext`（必装）+ `ext-syntax-highlight.mext`**
- 为什么：这是为洛谷 2025 版 Markdown 量身做的扩展，写题解几乎覆盖全部特性。
- 覆盖语法：
  - 折叠框 `:::info / success / warning / error`（可嵌套、可 `:::info{open}` 默认展开）
  - 居中 `:::align{center}`、居右 `:::align{right}`、引言 `:::epigraph`
  - Tuack 表格 `:::cute-table{tuack}`
  - 代码 ` ```cpp line-numbers ` 行号、` ```cpp lines=2-3 ` 区间高亮
  - 表格合并单元格（`^` 向上、` <` 向左）
- 贴心：工具栏会出现 🌱 模板面板，内置 13 个中文标签，不用背语法直接点。

### 🧭 画流程图 / 思维导图（架构、算法、读书笔记）

- **推荐：`ext-flowchart.mext` + `ext-mindmap.mext`**
- 为什么：把思路画成图比纯文字清楚。两者都直接吃 **Mermaid 语法**——网上现成的 `flowchart TD …` 或 `mindmap` 代码粘进来就能渲染，不用另学一套；思维导图也认 Markdown 标题/列表层级，顺手就能用。
- 用法要点：用 ` ```mermaid ` 代码块写 `flowchart`/`mindmap`，或 ` ```mindmap `；支持菱形判断、子图、着色（`:::类名` / `classDef`）、回边、双向箭头。自动分层 / 双侧平衡布局，明暗自适应，导出 HTML 保留图。
- 需要统计图表（柱/折/饼/散点…）再补 `ext-chart.mext`。

### 📐 数学老师 / 几何题解 / 要画图的理工党

- **推荐：`ext-geometry.mext`（必装）**
- 为什么：写几何题解、教案、实验示意图时，用声明式 DSL 定义点、连线、画圆、标角，自动吐出可缩放的 SVG，比截图清晰、比手画规整。
- 用法要点：用 ` ```geometry ` 代码块（或 `:::geometry` 容器），先 `point A = (0, 0)` 定义坐标点，再 `polygon / circle / angle / right` 等绘制；支持派生点（中点 midpoint、外心 circumcenter、重心 centroid、垂足 foot、旋转 rotate、交点 intersect…）和安全表达式（sqrt / pi / sin / cos，不使用 eval）。自动取景、明暗自适应，导出的 HTML 保留图形。

### 🔢 数学 / 理工科（偏公式、不画图）

- **推荐：本体已够用，按需补扩展**
- 为什么：KaTeX 全内嵌，矩阵、分段函数、多行对齐都支持。若文档里还要大段解释性代码，补一个 `ext-syntax-highlight.mext`；需要画几何图形，再加 `ext-geometry.mext`。

### 🏢 团队 / 出版 / 需要统一风格

- **推荐：`ext-admonition.mext` + `ext-syntax-highlight.mext` + 自写扩展**
- 为什么：用容器块统一「注意 / 警告 / 提示」的视觉语言，代码高亮统一配色；再按团队规范写一个 `.mext`（例如统一标题前缀、自动插页脚、专属快捷键），分发给成员导入，风格立刻一致。
- 进阶：`ctx.md.preTransform` 可以在解析前改写整篇 Markdown，`ctx.app.panel` 还能弹出自己的面板。

### 🌱 只想轻量记录

- **推荐：先不装，或只装 `ext-emoji.mext`**
- 为什么：编辑器本体已经覆盖了 Markdown、公式、保存、主题、大纲。轻量记录时保持零扩展最干净；想要一点活泼感，挂一个 Emoji 扩展就够。

## 六、三步就开始

1. **打开它**：双击同目录的 `index.html`，浏览器里就有一个编辑器。
2. **直接写**：左边写、右边看；把 `.md` 文件拖进窗口也能直接打开。
3. **存下来**：`Ctrl + S` 存成 Markdown，或导出 HTML 发出去。不存也没关系，它已经在本机记住了。

---

## 七、安全与隐私

- 所有内容只存在你的浏览器本地存储，不经过任何服务器。
- 扩展是 JavaScript，只导入你信任的来源；停用扩展会触发 `dispose` 清理其注入的样式与监听。扩展内的表达式求值（如几何作图）使用安全解析，不使用 `eval`。
- 想换设备？带上 `index.html` 和你需要用的 `.mext` 文件即可，无需账号。
