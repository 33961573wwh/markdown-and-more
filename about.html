01 / 能力

边写边看

仅编辑 / 分屏 / 仅预览三种视图，中间分隔条可拖动。滚动时两边按比例对齐，滚哪边都不会错位。

长文靠大纲面板跳转，代码块里的假标题不会被误收进去。

三视图 · 双向滚动同步 · 大纲

公式不用联网

KaTeX 引擎与 20 个字体文件全部内嵌，断网也照样渲染。支持 $…$、$$…$$、\(…\)、\[…\] 四种写法。

$5 这类价格不会误判成公式，代码块里的美元符也不会被打扰。

KaTeX 全内嵌 · 公式缓存 · 错误就地提示

不会丢字

停止输入半秒后自动写入本机存储，标题和正文一起存。下次打开原样恢复，连光标上下文都在。

顶栏小圆点实时显示保存状态，绿了就是存好了。

localStorage · 500ms 防抖 · 自动恢复

随时带走

CtrlS 存成 .md；「导出 HTML」生成独立单文件，排版、公式字体、代码配色、扩展注入的 SVG 一起打包。

想打印？打印样式只输出正文，顶栏和编辑区自动隐藏。

.md 保存 · 独立 HTML · 打印友好

暗色主题下代码高亮、公式和图形扩展也跟着换色，不是简单反相。

// 一个扩展就是一个 .mext 文件
api.register({
  name: '流程图',
  icon: '🔀',
  init: function (ctx) {
    // 先把 ```mermaid 改成私有块，绕开代码高亮扩展
    ctx.md.preTransform(function (text) { return text; });
    ctx.md.addBlockRule({
      test: function (lines, i) {
        return 0;   // 0 = 不匹配
      },
      render: function (lines, i, n) {
        return '<svg>…</svg>';
      }
    });
  },
  dispose: function () { /* 收尾 */ }
});

扩展会作为 JavaScript 在本页执行，只导入你信任的来源。同名扩展再次导入会替换旧的，不会叠加；样式统一以 -ext-style 结尾的 id 注入，导出 HTML 时会被一起打包。

06 / 上手

打开它

双击 index.html，浏览器里就有一个编辑器。想放到手机上？把文件发过去，用浏览器打开即可。

直接写

左边写，右边看。也可以把 .md 文件拖进窗口打开，内容会自动接上上次的位置。

存下来

CtrlS 存成 Markdown，或者导出 HTML 发出去。不存也没关系，它已经在本地记住了。

要画图或写题解：点顶栏「扩展」→「导入扩展」选对应的 .mext，工具栏会多出模板按钮，点一下就能插入示例，改文字即可。
