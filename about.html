它擅长什么

没有账号、没有同步、没有付费墙。你要的写作工具该有的，一个不少。

01 / 能力

边写边看

仅编辑 / 分屏 / 仅预览三种视图，中间分隔条可拖动。滚动时两边按比例对齐，滚哪边都不会错位。

长文靠大纲面板跳转，代码块里的假标题不会被误收进去。

三视图 · 双向滚动同步 · 大纲

公式不用联网

KaTeX 引擎与 20 个字体文件全部内嵌，断网也照样渲染。支持 $…$、$$…$$、\(…\)、\[…\] 四种写法。

$5 这类价格不会误判成公式，代码块里的美元符也不会被打扰。

KaTeX 全内嵌 · 公式缓存 · 错误就地提示

不会丢字

停止输入半秒后自动写入本机存储，标题和正文一起存。下次打开原样恢复，连光标上下文都在。

顶栏小圆点实时显示保存状态，绿了就是存好了。

localStorage · 500ms 防抖 · 自动恢复

随时带走

CtrlS 存成 .md；「导出 HTML」生成独立单文件，排版、公式字体、代码配色、扩展样式一起打包。

想打印？打印样式只输出正文，顶栏和编辑区自动隐藏。

.md 保存 · 独立 HTML · 打印友好

七套主题

晴川、琥珀、青松、碧海、绯樱、夜航、石墨。每套都有独立的强调色、选区、高亮与代码底纹，选完记在本机。

暗色主题下代码高亮与公式也跟着换色，不是简单反相。

7 主题 · 记忆选择 · 高亮联动

能长出新语法

一个 .mext 文件就是一段 JS，导入后即可改写解析规则、往工具栏加按钮、注册快捷键。

不想用了随时停用，扩展注入的样式会被一起清理干净。

.mext 扩展 · 热导入 · 可停用

里面是什么

整个编辑器就是一层解析器加三层界面，扩展从底部插进来，不碰主干。

04 / 扩展
文件能力说明
ext-luogu.mext 洛谷新特性 折叠框（四级、可嵌套、可默认展开）、居中居右、引言、Tuack 表格、^/< 合并单元格、代码行号与区间高亮，附中文模板面板。
ext-syntax-highlight.mext 代码高亮 30 多种语言的关键字着色，明暗主题自适应，导出 HTML 也保留颜色；与洛谷扩展协同，代码块交给它统一处理。
ext-admonition.mext 容器块 用 :::tip 标题 … ::: 写提示框、警告框，需要时会让位给洛谷的 :::info 语法。
ext-emoji.mext Emoji 短码 把 :smile: 这类短码换成表情，并在工具栏加一个插入按钮；代码块里的短码不动。
  • ctx.md.addBlockRule定义新的块级语法，返回消耗行数
  • ctx.md.postTransform渲染完成后改写 HTML
  • ctx.md.inline渲染一段行内文本
  • ctx.ui.addButton往工具栏加按钮
  • ctx.ui.addCommand注册专属快捷键
  • ctx.app.panel弹出自己的面板并拿到容器元素
  • dispose停用时清理注入的样式与监听
// 一个扩展就是一个 .mext 文件
api.register({
  name: '容器块语法',
  icon: '📦',
  init: function (ctx) {
    ctx.md.addBlockRule({
      test: function (lines, i) {
        return 0;   // 0 = 不匹配
      },
      render: function (lines, i, n) {
        return '<div>…</div>';
      }
    });
  },
  dispose: function () { /* 收尾 */ }
});

扩展会作为 JavaScript 在本页执行，只导入你信任的来源。同名扩展再次导入会替换旧的，不会叠加。

不需要安装，也不需要建账号。

05 / 上手

打开它

双击 index.html，浏览器里就有一个编辑器。想放到手机上？把文件发过去，用浏览器打开即可。

直接写

左边写，右边看。也可以把 .md 文件拖进窗口打开，内容会自动接上上次的位置。

存下来

CtrlS 存成 Markdown，或者导出 HTML 发出去。不存也没关系，它已经在本地记住了。
